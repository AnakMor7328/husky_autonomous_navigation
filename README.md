# Husky Project

Repositorio para el desarrollo del proyecto con Husky usando ROS 2, visión por computadora, navegación y coordinación robótica.

## Estructura

- `ros2_ws/src/`: paquetes de ROS 2
- `scripts/`: scripts de ejecución
- `docs/`: documentación
- `models/`: modelos de visión
- `datasets/`: imágenes, videos o datos de prueba
- `notebooks/`: pruebas en Jupyter
- `simulations/`: archivos de simulación

## Objetivo

Desarrollar módulos de percepción, navegación y control para el robot Husky.
